# RJA website concept

A public, noindex design concept prepared by [Roupiço Group](https://roupicogroup.com/) for RJA. This is not an official RJA website. Product listings, prices, accounts and enquiries are demonstrations only.

Open `index.html` for the route chooser. The Shop and Services pages include comparison links to alternate layouts. The Shop hero search and categories open `catalogue.html`, which has category filters, sorting and a guest cart quote preview. Product images and prices remain illustrative.
